# Актуализация номеров абонентов

Готовый статичный сайт-таблица для учёта номеров абонентов. Бэкенда и
сборки не требуется — открыл `index.html` и работаешь.

Записи группируются **по месяцам** и внутри месяца **разделяются по
дням**. Оформление спокойное, компактное и одинаковое и на странице, и в
выгрузках — это рабочий инструмент, а не витрина.

## Поля

- **Адрес**
- **Логин**
- **Дата**
- **Номер телефона**

## Что умеет

- **Добавление** — заполните форму и нажмите <kbd>Enter</kbd> (или
  «Добавить»); строка появляется в таблице и уходит в Excel.
- **Загрузить Excel** — импорт данных из `.xlsx` (с заменой или
  добавлением к текущим).
- **Выгрузить Excel** — экспорт в `.xlsx`: каждый месяц на своём листе
  со своим (приглушённым) цветом, внутри — разделители дней.
- **Выгрузить HTML** — автономный `.html` с той же компактной таблицей,
  который можно открыть где угодно без зависимостей.
- **Привязать Excel** (Chrome/Edge) — один раз выбрать файл, и дальше
  каждая запись пишется в него автоматически (File System Access API).

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx serve .
```

## Хранение данных

Данные дублируются в `localStorage` браузера — это источник для пересборки
файла и предпросмотра. Excel-файл всегда отражает весь набор. Сборку и
чтение `.xlsx` выполняет [ExcelJS](https://github.com/exceljs/exceljs)
(подключается по CDN).

## Оформление

Палитра спокойная: светлый фон, тонкие рамки. За каждым месяцем закреплён
свой приглушённый цвет (см. `MONTH_COLORS` в `js/app.js` и классы
`.month-*` в `css/style.css`) — цвета согласованы между страницей, Excel и
HTML-выгрузкой.

## Подключение бэкенда (потом)

Доступ к данным изолирован в объекте `Store` в `js/app.js`
(`all`, `add`, `remove`, `replaceAll`, `addMany`). Чтобы перевести сайт на
общий бэкенд, замените тела этих методов на запросы к вашему API.

## Деплой

Любой статический хостинг: Vercel, GitHub Pages, Netlify. Файл
`vercel.json` уже включён.
